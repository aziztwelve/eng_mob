- `📱Light Theme`: Entry Flow, Game Play, Streak & Mieo Talk, Profile, Leaderboard, Shop, Home, Overlays, Live Questions, Review Mistakes, Stories, Result, New Account Progress, Login.

Nested SVG/raw-image assets are in `../screen-assets`; the first implementation batch is in `../mieo-login` and is wired into the login screen.
