Проверка LingoIQ на Redmi 8A через Metro, 18.10.2026.

Остановлена по просьбе пользователя «заканчиваем работу».

Проверено на телефоне:
- Экран входа: исходный вид, ошибки при пустых полях, прокрутка до ссылки начала обучения.
- «Забыли пароль?» показывает заглушку «Восстановление пароля скоро появится».
- Пройден весь маршрут из шести экранов: приветствие → цель → возраст → уровень → время занятий → регистрация.
- На цели «Дальше» без выбора не переводит вперёд.
- Выбраны: Работа и карьера, 25–34, A1, вечером.
- Возврат с времени занятий к уровню сохраняет выбор A1.
- Открыта регистрация, выполнена попытка отправить пустую форму, открыт ввод с клавиатурой; снимки сохранены.

Не завершено из-за остановки: успешная регистрация, повторный вход, проверка сохранённого профиля через backend, Google OAuth, отдельный маршрут /auth/register.
Новый тестовый аккаунт не создавался, формы с настоящими учётными данными не отправлялись.

Технически: первый запуск Metro с heap 512 МБ упал с JavaScript heap out of memory. По просьбе пользователя ограничение NODE_OPTIONS снято. Холодная генерация bundle завершилась за 129828 мс (8040 modules); после bundle root mounted ~31539 мс, splash ready to hide ~33420 мс — показатели dev-запуска, не релизного APK.
APK/Gradle/EAS не запускались. Код приложения не менялся. Скриншоты — в этой папке.
